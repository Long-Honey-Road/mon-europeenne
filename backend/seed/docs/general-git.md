> Учебная инструкция: составлена для демонстрации buddy, не является регламентом Авито.

## Ветки
Ветка создаётся от `main` и называется по смыслу изменения: `feat/user-search`, `fix/sse-reconnect`.
Номер задачи пишется в заголовок PR, а не в имя ветки.

## Коммиты
Сообщение коммита: одна строка в повелительном наклонении на английском (`Add user search`), тело только если
неочевидно «зачем». Не смешивай в одном коммите рефакторинг и изменение поведения.

## Слияние
В `main` попадает только через PR с зелёным CI. Прямые пуши в `main` закрыты.
