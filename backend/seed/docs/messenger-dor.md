> Учебная инструкция: составлена для демонстрации buddy, не является регламентом Авито.

## Задача готова к работе, если
- понятна цель и как проверить результат;
- есть оценка и нет блокирующих зависимостей;
- для изменений API согласован контракт.

## Задача сделана, если
- код слит в `main`, CI зелёный;
- изменение выкачено на staging и проверено;
- обновлена документация, если менялось поведение.
