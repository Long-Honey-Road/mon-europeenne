> Учебная инструкция: составлена для демонстрации buddy, не является регламентом Авито.

## Какие тесты пишем
Unit-тесты на логику, интеграционные тесты с Postgres и Kafka в Docker (testcontainers), контрактные тесты на
API.

## Как запускать
`make test` гоняет unit-тесты, `make test-integration` поднимает зависимости. Перед PR запускай оба.

## Покрытие
Порог покрытия 80% по изменённому коду, отчёт в CI. Тест пишется до исправления бага: сначала падающий тест.
