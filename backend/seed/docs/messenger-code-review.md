> Учебная инструкция: составлена для демонстрации buddy, не является регламентом Авито.

## Аппрувы
В репозиториях Messenger пулреквест сливается после **одного аппрува** от CODEOWNER затронутого кода и зелёного
CI. Второй аппрув не нужен: команда маленькая, ждать второго ревьюера дольше, чем исправлять.

## Обязательные проверки
- Линтер `golangci-lint` без новых замечаний.
- Покрытие изменённого кода тестами не ниже 80%.
- Для изменений API: обновлённая спецификация и пример запроса в описании PR.

## Кто ревьюит стажёров
Первые PR стажёра ревьюит наставник, даже если CODEOWNER другой человек.
